HOW NAVIGATION WORKS
--------------------
• Main shell: src/App.jsx
• There is NO React Router for the logged-in app. Navigation uses React state:
    currentPage (string) + setCurrentPage passed to Header and LeftSidebar.
• Exception: When !user, the app shows Login or Register based on
    window.location.pathname === '/register' (see App.jsx). /login is normalized to /.

• Entry: src/main.jsx → App.jsx
